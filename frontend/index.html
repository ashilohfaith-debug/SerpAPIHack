Assistive Operating System Agent · Windows 10 & 11

Use your Windows PC by talking.

A voice assistant engineered specifically for blind and low-vision people. RELAY inspects your screen via Windows UI Automation, announces actions before executing them, confirms changes by re-observing, and recovers out loud.

How to Use Guide Command Library
Talk Key: Ctrl+Alt+Space Toggle: Ctrl+Alt+R Stop: Ctrl+Alt+. Emergency: Ctrl+Alt+Backspace
Core Operational Guarantees
  • [01] Transparent Operator: Acts only when asked. Never claims a success it didn't directly verify through the accessibility API.
  • [02] Screen-Off Capability: Operates entirely without visual output. Sound design and spoken descriptions replace display dependency.
  • [03] Zero-Guess Safety Gate: Risky actions (deleting files, sending emails, shutting down) mandate strict verbal confirmation phrases.
  • [04] Offline Sovereignty: Whisper speech recognition and Piper voice run locally on basic 4 GB dual-core laptops. No cloud required.

How to Use RELAY

Complete step-by-step operational guide for blind users, caregivers, and accessibility developers.

STEP 01 INSTALLATION

Setup & First Run

RELAY installs without Python knowledge. Run the installer script or double-click Install Relay.cmd from the package. It sets up shortcuts and downloads the local speech recognition and voice models once (~140 MB).

RELAY.cmd --install RELAY.cmd --check
STEP 02 ACTIVATION

The Talk Key & Wake Word

Press Ctrl+Alt+Space from anywhere. You will hear an ascending chirp earcon, indicating RELAY is listening. Alternatively, use the hands-free wake word: "Relay, what time is it?" Press Ctrl+Alt+R to start or exit RELAY.

Ctrl+Alt+Space # Talk Key (chirp) Ctrl+Alt+R # Launch / Close RELAY
STEP 03 NAVIGATION

Screen & Document Reading

Ask RELAY to read what's currently open. It extracts real structural content rather than guessing from images. Supports pausing, continuing, jumping to headings, or falling back to RapidOCR when a window lacks accessibility tags.

"what's on my screen" "read the page" / "read with OCR" "next heading" / "read the PDF bill"
STEP 04 WRITING

Dictation & Text Editing

Inject text into any active text editor, form, or document. Dictation types naturally without keyboard fatigue. RELAY verifies that the characters registered in the active control.

"type Hello, how are you?" "start dictation" ... "stop dictation" "select all" / "undo" / "save as notes"
STEP 05 HARDWARE

Smart Headphone & Volume Routing

Headphones (wired, USB-C, or Bluetooth) are detected automatically. Speech moves to your ears instantly. If headphones are unplugged mid-reading, RELAY pauses automatically to prevent reading private content out loud to the room.

"volume up" / "volume down" "speak slower" / "where is sound going" "turn on Bluetooth" / "battery status"
STEP 06 SAFETY

Safety Confirmations & Emergency Halt

Irreversible actions (deleting files, sending emails, restarting PC) activate the Safety Gate. RELAY plays an alert earcon and demands an explicit phrase. If anything goes wrong, press Ctrl+Alt+Backspace to halt everything immediately.

"delete this file" -> "say confirm delete" Ctrl+Alt+. # Silence / Pause Ctrl+Alt+Backspace # Emergency Halt
STEP 07 AI ANSWERS

FreeLLMAPI & Sarvam Voice

Connect FreeLLMAPI for ChatGPT-style general knowledge answers spoken aloud sentence-by-sentence. Add a Sarvam AI key to unlock natural Indian voices (Bulbul) and Saaras multilingual speech recognition understanding Indian accents.

RELAY_LLM_URL=http://127.0.0.1:31415/v1 RELAY_LLM_KEY=freellmapi-... SARVAM_API_KEY=sk_...
STEP 08 PANEL

Companion Mirror Panel

Caregivers or developers can open the web panel to mirror what RELAY is seeing and saying in real-time. Closing the web panel does not stop RELAY; the voice assistant runs headlessly in the Windows session.

http://127.0.0.1:8765/?token=... (or run frontend/index.html standalone)

5-Stage Deterministic Pipeline

Observable and verifiable at every stage. No black-box autonomous actions.

STAGE 01

Speech In

faster-whisper transcribes voice locally in ~180 ms using int8 quantized weights.

STAGE 02

Intent & Safety

Deterministic regex grammar matches command. Destructive actions hold for confirmation.

STAGE 03

Windows UIA

COM MTA worker queries UI Automation tree without blocking audio capture.

STAGE 04

Verification

Re-observes screen state. Never announces success unless verified in the OS.

STAGE 05

Speech Out

Piper TTS speaks sentence by sentence. Sarvam Bulbul voice optional for Indian accents.

Auditory UX & Spatial Earcons

Acoustic feedback enables blind users to maintain situational awareness at all times.

WAKE / TALK
▶

Ascending Chirp

440 Hz → 880 Hz sweep. Plays when microphone starts recording.

VERIFIED
▶

Major Triad Chime

C5-E5-G5 chord. Confirms that UI Automation observed requested change.

SAFETY GATE
▶

Caution Double Pulse

Two 360 Hz pulses. Signals that a destructive action requires verbal confirmation.

EMERGENCY STOP
▶

Descending Sweep

280 Hz → 90 Hz drop. Halts all active operations, TTS playback, and planners.
